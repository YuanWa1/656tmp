Environment-map mode

Three soap bubbles in front of an HDR panorama, from one fixed camera with no geometry. The bubbles exist only as a view-space normal map and a coverage mask baked from the path tracer's scene (scripts/bake_normal_map.py). Normals are decoded with N = normalize(tex * 2.0 - 1.0).

Each pixel's view ray comes from the same camera used for baking. The reflection direction is reflect(D, N), rotated by the environment orientation and mapped to equirectangular coordinates. Lookups use explicit gradients so the panorama's wrap-around seam never shows, and the HDR is mipmapped so curved silhouettes do not shimmer as the environment turns.

Each bubble also shows its back film: for a sphere the exit normal is the entry normal with its along-ray component flipped, so it follows from the normal map and the view ray alone. Front reflection, back reflection and the transmitted panorama are weighted by a stylized thin-film reflectance. "Mirror spheres" swaps the film for polished silver to show the raw environment reflection. Panoramas: Poly Haven (CC0).

Normal-map mode

The same scene seen from one fixed camera, with no geometry: every pixel's surface comes from a normal map baked from the path tracer's scene (scripts/bake_normal_map.py). Normals are decoded with N = normalize(tex * 2.0 - 1.0); the renormalization undoes the shortening caused by texture filtering. A point light follows the mouse at an adjustable height above the image.

Walls and floor use Lambert diffuse plus a faint Fresnel-weighted Blinn-Phong highlight. Bubbles transmit the background (a second normal map plus an albedo map describe the surface behind them) and reflect a soft environment and the light through an Airy thin-film reflectance. The film is stylized rather than strictly physical: its thickness slides with the angle at which the light hits each point, so moving the light sweeps the color bands across the bubbles, and the colors are pushed toward higher saturation. The thickness field itself is static noise, thinner toward the top of each bubble, so nothing flickers while the light is still.

Description

This is a progressive Monte Carlo path tracer implemented in a WebGL fragment shader. It traces multiple jittered rays per frame and blends them over time to approximate global illumination, soft area-light shadows, and color bleeding. Moving or rotating the camera immediately resets sample accumulation for responsive navigation, while keeping the camera still allows the noisy image to converge into a clean, smooth result.

The scene features three hollow soap bubbles enclosed in an illuminated studio. Each bubble shell is modeled as an air–soap film–air interface with a film IOR of 1.333. Thin-film interference is evaluated using the Airy reflectance formula across RGB wavelengths, producing realistic iridescent colors. Film thickness smoothly varies between 200 nm and 700 nm across each bubble using 3D Perlin noise.
