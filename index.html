Description

A flat quad is lit per pixel with the Blinn-Phong model. Its surface detail comes entirely from a tangent-space normal map, which makes the flat image look like it has depth.

Textures. The albedo is uploaded as sRGB, so sampling returns linear color. The normal map is uploaded as raw RGBA8 and decoded with N = normalize(tex * 2.0 - 1.0). The renormalize is needed because mipmap filtering shortens the vector. Maps authored in the DirectX convention can be handled by flipping the green channel.

Light. A point light sits at the mouse position, at an adjustable height above the plane. L is computed in aspect-corrected units so the light falls off evenly in x and y on non-square images. The view is orthographic, with V = (0, 0, 1).

Shading. Diffuse is max(N·L, 0). Specular uses the half vector H = normalize(L + V) and pow(max(N·H, 0), shininess). It only applies where N·L > 0 and fades out near the terminator, so surfaces facing away from the light never get a stray highlight. Ambient, diffuse and specular are summed in linear space, then gamma-encoded for display.

Controls. The panel adjusts light height, specular strength, shininess and ambient. It also switches between the shaded result, the diffuse term alone and the decoded normals, and can orbit the light automatically.

Uploads. Replace the albedo in slot 0 or the normal map in slot 1 with a local image. Albedo defaults to sRGB; normal maps default to linear RGBA8. Uploading a normal map updates the canvas aspect ratio. Slots 2–7 are retained from the shared framework for other shaders.
