Description

This path tracer is a WebGL fragment-shader progressive renderer that uses Monte Carlo path tracing to approximate global illumination. For each pixel, it traces 2 jittered samples per frame, with paths supporting diffuse reflection, dielectric reflection/refraction, Schlick Fresnel approximation, area-light sampling, shadow-ray visibility checks, and Russian roulette termination. The scene is a Cornell-box-style setup with colored walls, a rectangular ceiling light, glass spheres, and a small triangle-based pyramid. Instead of rendering a clean image in a single pass, the renderer progressively accumulates samples over time. Each frame generates new randomized samples using per-pixel, per-sample, and per-bounce seeds, then blends the current result with the previous frame using a running average. As more frames are drawn, the initially noisy image gradually converges, producing smoother lighting, softer shadows, indirect illumination, and more stable glass effects.
